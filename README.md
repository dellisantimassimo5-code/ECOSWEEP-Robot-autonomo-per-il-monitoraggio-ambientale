# ECOSWEEP-Robot-autonomo-per-il-monitoraggio-ambientale
EcoSweep è un prototipo di robot mobile autonomo (AGV) per ambienti industriali, progettato per pulizia, monitoraggio e prevenzione. Raccoglie polveri e residui, rileva parametri ambientali (gas, particolato, temperatura) e segnala anomalie. Integra hardware, software e ROS2 con dashboard dati.
